# Copilot instructions for this repository

Use `AGENTS.md` as the main implementation specification.

- Inspect the existing app structure before changing code.
- Reuse the current framework, styling approach, icons, and dependencies.
- Match the RoutaX reference: light blue-gray background, white rounded cards, vivid blue accents, amber highlights, compact fleet KPIs, central cargo visualization, selectable truck list, route map, vehicle health, and camera preview.
- Build reusable components and keep demo data separate from UI.
- Implement responsive desktop/tablet/mobile layouts and accessible interactions.
- Use local mock/demo data unless a real backend is already wired up.
- Never represent mock GPS, video, calls, or API responses as live integrations.
- Avoid unrelated refactors and unnecessary dependencies.
- Run available lint, type-check, and build scripts; summarize results.
